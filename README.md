#Algolens

An interactive algorithm visualizer built with HTML, CSS, and Javascript.

##Features
-Bubble sort animation
-Selection sort animation
-Random array animation
-Color coded comparisons in real time


##How to use
1. Click "New array" to generate random bars
2. Click "Bubble sort" or "Selection sort" to watch the algorithm run
3. Red = being compared, Yellow = current minimum, White = stored
